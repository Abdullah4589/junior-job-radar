# Dashboard

Next.js overview for Junior Job Radar. The page reads `../data/catalog/trends.json` and `../data/catalog/postings.json` when it is built. There are no job-board requests and no environment variables.

```powershell
npm install
npm run dev
npm run lint
npm run build
```

Filters and the postings table are Day 5. See [docs/ROADMAP.md](../docs/ROADMAP.md).
